Example: if you want to train a model to predict house prices you need a structured dataset of house prices, location, size, etc.

2. Describe the relational database mental model.
Answer: Relational database in which all data is related to each other like if we have user data then we have a data of their orders, address, etc. Table in which we store data and columns in which we store information about the data. Rows in which we store data.

3. Explain the concept of a primary key.
Answer: Primary key is colume which is unique in table like user id, order id, etc.
Primary keys must be unique and non-null because if the 2 user id is same then it will create a confusion and the primary key role is unique identification of a row.

4. Explain what a database schema is.
Answer: Database schema is formal structure of database which is used to store data all information like name, address, phone number, etc. Schema is like a blueprint of database and it maintain the link between tables. It also maintain the data integrity and data consistency.

5. Explain how relationships between tables work in relational databases. 
Answer: Relationship between tables work in relational databases with the help of primary key and foreign key. Primary key is unique in table and foreign key is the primary key of another table. It helps to extract or retive data from multiple tables based on the relationship between them like user table and order table in which user table has primary key user id and order table has foreign key user id which is the primary key of user table and it helps to maintain the data integrity and data consistency like which user has placed which order and how many orders has been placed by each user.
